# Privacy Policy

wtmux is a terminal multiplexer that runs entirely on your local machine (Windows, macOS, or Linux).

- wtmux does not collect, store, or transmit any personal data, usage data, or telemetry.
- wtmux does not connect to the internet or any external server under any circumstances.
- Configuration files (e.g. `config.toml`) and session data are stored only on your local machine and are never transmitted anywhere.

If you have any questions about this policy, please open an issue at
https://github.com/fukuyori/wtmux/issues

Last updated: 2026-07-20

# プライバシーポリシー(日本語)

wtmuxは、お使いの端末（Windows / macOS / Linux）上でローカルに動作するターミナルマルチプレクサです。

- wtmuxは、個人情報・利用状況データ・テレメトリ等、いかなるデータも収集・保存・送信しません。
- wtmuxは、いかなる状況においてもインターネットや外部サーバーに接続しません。
- 設定ファイル(`config.toml`など)やセッションデータは利用者のローカル端末内にのみ保存され、外部に送信されることはありません。
